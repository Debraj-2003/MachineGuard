# MachineGuard

## AI-Powered Predictive Maintenance System

MachineGuard is an AI-based predictive maintenance system designed to predict the probability of machine failure using sensor measurements such as temperature, rotational speed, torque, and tool wear.

The system uses machine learning models to identify machines that may be at risk of failure and provides a risk score to support preventive maintenance decisions.

---

## Features

- Machine failure prediction using machine sensor data
- Comparison of multiple machine learning models
- XGBoost-based primary prediction model
- Random Forest and Logistic Regression as comparison models
- Failure probability and machine risk classification
- Confusion matrix and ROC-AUC based model evaluation
- Feature importance analysis
- SHAP-based model explainability
- Anomaly detection using Isolation Forest
- Interactive Flask web application
- Machine dashboard with risk information
- Individual machine prediction
- Manual sensor-data based failure prediction

## Machine Learning Models

Three supervised learning models were trained and compared:

### 1. Logistic Regression

Used as the baseline classification model.

### 2. Random Forest

An ensemble-based classification model used for nonlinear relationships between machine sensor measurements and failure.

### 3. XGBoost

The primary model selected for MachineGuard because of its strong overall performance and high failure-detection capability.

---

## Model Performance

The models were evaluated using accuracy, precision, recall, F1-score, and ROC-AUC.

| Model | Accuracy | Precision | Recall | F1 Score | ROC-AUC |
|---|---:|---:|---:|---:|---:|
| Logistic Regression | 82.45% | 14.18% | 82.35% | 24.19% | 0.9070 |
| Random Forest | 98.20% | 75.00% | 70.59% | 72.73% | 0.9701 |
| XGBoost | 97.95% | 66.27% | 80.88% | 72.85% | 0.9701 |

### Selected Model

**XGBoost** is used as the primary MachineGuard prediction model.

Although Random Forest achieved slightly higher accuracy and precision, XGBoost achieved a higher recall for machine failures.

For predictive maintenance, recall is particularly important because failing to detect an actual machine failure can result in unexpected downtime and maintenance costs.

## Dataset

The project uses a machine predictive-maintenance dataset containing sensor and machine-operation information.

The main features include:

| Feature | Description |
|---|---|
| UDI | Unique machine identifier |
| Product ID | Product identifier |
| Type | Machine/product type |
| Air temperature | Ambient air temperature |
| Process temperature | Machine process temperature |
| Rotational speed | Machine rotational speed |
| Torque | Applied machine torque |
| Tool wear | Tool usage/wear |
| Machine failure | Target variable indicating machine failure |

Additional failure indicators in the dataset include:

- TWF — Tool Wear Failure
- HDF — Heat Dissipation Failure
- PWF — Power Failure
- OSF — Overstrain Failure
- RNF — Random Failure

The individual failure indicators were not used as input features for the primary prediction model to avoid target leakage.

---

## Feature Engineering

The categorical `Type` feature was converted into numerical columns using one-hot encoding.

The final model features are:

```text
Air_temperature_K
Process_temperature_K
Rotational_speed_rpm
Torque_Nm
Tool_wear_min
Type_L
Type_M
```

Identifiers and target-related failure columns were excluded from the model input.

## SHAP Explainability

SHAP (SHapley Additive exPlanations) is used to explain the predictions generated by the XGBoost model.

Instead of only predicting whether a machine is likely to fail, SHAP helps identify which features contributed to the prediction.

For example:

```text
Machine Failure Risk
        |
        v
     XGBoost
        |
        v
     SHAP
        |
        +--> Torque
        +--> Tool Wear
        +--> Rotational Speed
        +--> Temperature
```

The SHAP visualization is stored as:

```text
reports/figures/shap_summary.png
```

## Anomaly Detection

MachineGuard also includes anomaly detection using the Isolation Forest algorithm.

The purpose is to identify machines with unusual sensor patterns.

```text
Sensor Measurements
        |
        v
Isolation Forest
        |
        +---- Normal
        |
        +---- Anomaly
```

Anomaly detection complements failure prediction by identifying unusual operating conditions that may require further investigation.

---

## Risk Classification

The XGBoost failure probability is converted into a simple machine risk level.

| Failure Probability | Risk Level |
|---:|---|
| < 30% | Low Risk |
| 30% – 70% | Medium Risk |
| > 70% | High Risk |

Example:

```text
Failure Probability: 82.4%

Risk Level:
HIGH RISK
```
